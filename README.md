# FlexTimer

A simple walking countdown timer with oversized controls for easier tapping.

## Open It

Open `index.html` in any modern browser.

For local testing from this folder, you can also run:

```powershell
python -m http.server 49317 --bind 127.0.0.1
```

Then visit:

```text
http://127.0.0.1:49317/index.html
```

## Use It

Type a walk length from 1 to 999 minutes, press **Set**, then press **Start**. Use **Pause** or **Reset** as needed. The sound control clearly shows **Sound On** or **Sound Off**; turning sound on plays a short preview tone. When the timer finishes, it shows a large completion message, plays a continuous alarm if sound is on, and offers **Restart** to immediately start the same timer again.
